Ingresar

Pega el JWT del ecosistema. El gateway verifica la firma y cada microservicio aplica sus reglas de rol y de universidad.

Solo el token, o con el prefijo «Bearer ».
HTTP y WebSocket van por la misma ruta /graphql.
¿Aún no tienes token?

En ProposalBackend ejecuta python tools/generar_token.py. Imprime un token ADMIN de la universidad 900123456-1 que vence en cinco años.

Para el gateway: docker compose up -d --build en infrastructure levanta todo el ecosistema; solo el gateway, gradlew.bat bootRun en services/eter-graphql-gateway.

La demostración no necesita backend: los datos quedan en este navegador.
