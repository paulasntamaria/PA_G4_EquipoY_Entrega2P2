Simulador del Gateway ETER

Elige una operación GraphQL y mira qué componentes toca, en qué orden y qué responde cada uno. Cada paso sigue el código del gateway y cita el archivo y la línea. Las consultas no pasan por Kafka: Kafka entra solo cuando algo se escribe, después de responder. Pruébalo con «Crear un préstamo», «Dar de baja un activo» o «Suscripción a avisos» y mira los tópicos al fondo del diagrama. Los datos son de ejemplo y no se hace ninguna llamada real.
